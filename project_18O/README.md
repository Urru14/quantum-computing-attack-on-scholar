# Project: ¹⁸O with VQE (coming at the end of the series)

Nuclear shell-model ground state of ¹⁸O (a ¹⁶O core + 2 neutrons in the sd shell) found with the
variational quantum eigensolver, following A. Pérez-Obiol *et al.*, "Nuclear shell-model simulation in digital
quantum computers", *Scientific Reports* **13**, 12291 (2023).
